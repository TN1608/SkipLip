# SKIPLI AI WEBSITE

Welcome to the project repository! 👋

This project is organized into separate branches for the frontend and backend components. This `main` branch only contains this general overview README.md file.

## Branches 🌿

* **`frontend`**: Contains the source code for the user interface.
    * **Framework**: ReactJS
    * **Build Tool**: Vite
* **`backend`**: Contains the source code for the server-side logic and API.
    * **Framework**: ExpressJS
    * **Database**: Firebase
    * **AI API**: Gemini API 2.0 Flash

## 📝 Important Note

For detailed information regarding setup, running the application, and other specifics related to each part (frontend or backend), please **refer to the README.md file within each respective branch**.

Thank you for reading!
